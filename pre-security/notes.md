# Pre Security Notes (TryHackMe)

## NETWORK BASICS

### HTTP (HyperText Transfer Protocol)
- communication between browser and server (not secure)

### HTTPS (HyperText Transfer Protocol Secure)
- HTTP + encryption using TLS (Transport Layer Security)

- HTTP = request → response  
- Stateless = server does not remember previous requests  

---

## Ports
- numbered entry points (0–65535)

- 80 → HTTP (HyperText Transfer Protocol)  
- 443 → HTTPS (HyperText Transfer Protocol Secure)  
- 22 → SSH (Secure Shell)  
- 21 → FTP (File Transfer Protocol)  
- 53 → DNS (Domain Name System)  

- Port = identifies service (not physical)

---

## TCP / UDP

### TCP (Transmission Control Protocol)
- reliable, connection-based  
- ensures delivery and order  

### UDP (User Datagram Protocol)
- fast, no connection  
- no guarantee  

### TCP Three-Way Handshake
1. SYN (synchronize) → client starts connection  
2. SYN-ACK (acknowledge) → server accepts  
3. ACK (acknowledge) → client confirms  

### TCP Flags
- SYN = start connection  
- ACK = confirm data received  
- FIN = close connection  

---

## OSI MODEL

- 7 Application → HTTP, DNS  
- 6 Presentation → encryption, format  
- 5 Session → manage sessions  
- 4 Transport → TCP / UDP  
- 3 Network → IP (Internet Protocol)  
- 2 Data Link → MAC (Media Access Control)  
- 1 Physical → hardware  

---

## DNS

### DNS (Domain Name System)
- converts domain → IP  

### Flow
Client → Recursive Resolver → Root Server → TLD → Authoritative Server → IP  

- Recursive DNS = finds answer for client  
- Authoritative DNS = provides official answer  

**Important**
- Domain → IP = always works  
- IP → Domain = not always

## IP & NETWORKING

### IP (Internet Protocol)
- address of a device  

### Local IP
- 192.168.x.x  

### MAC (Media Access Control)
- unique hardware address  

- Switch → uses MAC  
- Router → uses IP

## PACKETS & FRAMES

- Packet = data at Network layer (IP)  
- Frame = packet + MAC (Data Link layer)  

### Encapsulation
Data → TCP → IP → Frame  

### Checksum
- verifies data integrity

## SECURITY BASICS

### Firewall
- controls network traffic (allow/block)

### DHCP (Dynamic Host Configuration Protocol)
- assigns IP automatically

### CIA Triad
- Confidentiality = secret
- Integrity = not modified
- Availability = accessible

### Hash
- fixed output from data
- used for passwords/integrity

### TLS (Transport Layer Security)
- encrypts data in HTTPS

### Without HTTPS
- data readable

### With HTTPS
- encrypted

### Sniffing
- capturing network traffic

### MITM (Man-In-The-Middle)

## WIRESHARK BASICS

### Wireshark
- network packet analyzer

### Columns
- Source → sender
- Destination → receiver
- Protocol → type
- Info → summary

### Protocols seen
- DNS → domain lookup
- TCP → connection
- HTTP → readable
- TLS → encrypted

### Example

- server responding to client
- ACK = acknowledge received data
- Seq/Ack = track data flow
- Len=0 = no data (control packet)
